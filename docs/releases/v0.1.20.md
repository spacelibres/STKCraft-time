# stkcraft-time 0.1.20

Release date: 2026-11-11

This release withdraws the container image added in 0.1.19. There is no
library change; 0.1.20 is functionally identical to 0.1.18.

## Removed

- `Dockerfile` and `.dockerignore`.
- The `publish-image` job in the `Release` workflow.
- The container sections in `README.md`, `docs/MCP.md`,
  `CONTRIBUTING.md` and the release checklist in `AGENTS.md`.
- The `ghcr.io/spacelibres/stkcraft-time` package on GitHub Packages.

## Registry state

- `0.1.19` is **yanked** on crates.io. It differs from 0.1.20 only in the
  withdrawn documentation, so new builds resolve to `0.1.20`.
- The GitHub Release and tag `v0.1.19` remain as history.

## What is still published

| Channel | Artifact |
|---|---|
| crates.io | `stkcraft-time` 0.1.20, API docs on docs.rs |
| GitHub Releases | release-mode binaries for Linux, macOS (x86_64, arm64) and Windows, plus `SHA256SUMS.txt` |
| GitHub Packages | nothing |

## Verification

- 108 tests by default, 120 with the `mcp` feature, all passing
- `cargo fmt --all -- --check`, clippy with `-D warnings` (both feature
  sets), `no_std`, `wasm32-unknown-unknown`, `thumbv7em-none-eabi`
- release build and release tests, MSRV 1.75, rustdoc with `-D warnings`
- `tests/version_sync.rs` confirms every documented version is `0.1.20`
