# stkcraft-time 0.2.0

Release date: 2026-11-13

This release adds explicit WebGeocalc-shaped GPS week/TOW input, GPS seconds
conversion and calendar output in Rust, Python, JavaScript and MCP. It also
adds native-style partitioned SCLK string/ET methods that preserve tested
native error symbols, and prevents unrepresentable SCLK-to-TAI results from
panicking. Captured NASA responses and independent CSPICE N0067 fixtures
record the tested values, kernel hashes, output bits and limits.

## Migration

This is a breaking 0.x minor release. Rust code exhaustively matching
`WgcGpsError` must handle `InvalidFormat`. MCP `et_to_sclk` now respects
single-partition metadata, including its partition prefix, and reports
native conversion errors instead of returning an absent clock string.
Downstream Cargo dependencies must explicitly accept version 0.2. Raw Rust
native SCLK-to-ET may return a non-finite value observed from CSPICE; checked
Python and JavaScript ET wrappers reject non-finite values.

The recorded inputs are finite samples and do not establish complete
WebGeocalc or cross-platform parity. Generic WGC request dispatch, CUSTOM
pictures and other unsupported formats remain documented limitations.
See `tests/reference/wgc-gps-input/README.md` and
`tests/reference/sclk-partition/README.md` for provenance and reproduction.
