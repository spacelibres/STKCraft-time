# stkcraft-time 0.1.9

Release date: 2026-11-11

This release publishes the crate to crates.io and fills in the registry
metadata. The library API and every conversion result are unchanged from
0.1.8.

## Installation

```toml
[dependencies]
stkcraft-time = "0.1.9"
```

```sh
cargo add stkcraft-time
cargo install stkcraft-time --features mcp --bin stkcraft-mcp
```

`no_std` with `alloc`:

```toml
stkcraft-time = { version = "0.1.9", default-features = false }
```
