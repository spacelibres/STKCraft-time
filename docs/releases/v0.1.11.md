# stkcraft-time 0.1.11

Release date: 2026-11-11

Documentation-only release. There is no library, kernel-format or numerical
change from 0.1.10.

## Fixes

- The 0.1.10 release notes stated the wrong test totals. The suite runs
  **104 tests by default** and **116 with the `mcp` feature**.

## Skill update

The `stkcraft-time` agent skill now records two behaviours introduced in
0.1.10, so generated code does not fall back to the old assumptions:

- formatting with `FormatOptions` when a carry could reach a leap second
  or a calendar day boundary, instead of the 86 400-second default of
  `iso8601`;
- per-partition SCLK validation, where a clock reset may start lower than
  the previous partition ended.

## Compatibility

No API or result change. Upgrade is optional.
