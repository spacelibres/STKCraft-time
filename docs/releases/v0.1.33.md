# stkcraft-time 0.1.33

Release date: 2026-11-12

This release adds native-style type-1 partitioned SCLK string conversion
and fixes selected N0067 discrete tick and partition-boundary behavior. Rust,
MCP and Python use the same core paths. An explicit `SclkStringContext`
retains native component-parser history; a fresh context starts a separate
history. MCP retains it per stdio session.

Time-conversion bounds round accumulated raw partition durations. String
encoding follows SCENCD endpoint rounding, so the two domains can differ.
Legacy field-vector helpers retain their existing partition restrictions.
For a partitioned MCP ET query, `ticks` is null when continuous conversion
fails but the discrete string conversion succeeds; `clock_string` can also
be null if decoding fails.

The independent CSPICE N0067 reference corpus includes MRO and synthetic
kernels, parser history, fractional endpoints, discrete ET boundaries,
metadata errors, 6,008 large-field, 1,004 large-offset and 80 width cases.
Reference artifacts and checksums are in `tests/reference/sclk-partition`.
These are finite platform/kernel samples, not proof of exhaustive SCLK or
WebGeocalc parity. JavaScript native partition-aware strings remain
unavailable and are identified as such in the binding inventory.

The WASM adapter updates the esbuild development dependency to 0.28.2 to
address GHSA-g7r4-m6w7-qqqr. The adapter browser test uses esbuild as a
bundler; it does not start the affected esbuild development server.
