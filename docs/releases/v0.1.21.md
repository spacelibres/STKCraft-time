## Scope of the claims

The wiki states only figures published by NAIF, IAU or IERS, or measured in
this repository with a command that reproduces them. It also records the
limits explicitly: no subdaily EOP terms, no EOP uncertainty propagation, no
leap-second prediction, SCLK type 1 only, and no UT1 comparison with
WebGeocalc because that API has no UT1 time system.
