# stkcraft-time 0.1.13

Release date: 2026-11-11

This release automates the crates.io step and makes the install command
visible at the top of the README. There is no library change.

## Automatic crates.io publish

The `Release` workflow now has a `publish-crates` job that runs after the
GitHub Release is created and uploads the tagged version with
`cargo publish --locked`.

- It reads the version from `Cargo.toml`, so the job cannot drift from the
  tag.
- It queries the crates.io API first and skips when that version already
  exists, so a re-run or a hand-published tag stays green.
- It skips when the `CARGO_REGISTRY_TOKEN` repository secret is absent,
  and prints why. Store the token at
  **Settings → Secrets and variables → Actions** to enable publishing.

Manual publishing still works and is documented in `CONTRIBUTING.md`:

```sh
cargo login          # or set CARGO_REGISTRY_TOKEN
cargo publish --locked
```

## README

The install command is now stated right below the badges:

```sh
cargo add stkcraft-time
```

The installation section puts `cargo add` before the `[dependencies]`
snippet, and keeps the `no_std`, MCP binary and git-tag variants.

## Compatibility

No API or numerical change. Upgrade is optional.
