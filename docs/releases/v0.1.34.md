# stkcraft-time 0.1.34

Release date: 2026-11-12

This release adds `wgc_gps::gps_seconds_to_week_tow` and its Python binding
for the exercised WebGeocalc GPS-seconds-to-week/TOW display path. It uses
an explicit LSK and the observed N0067 TAI→TDB→TAI binary64 operation order.
The displayed week saturates whole GPS seconds to i32 before integer division;
the full remainder uses shortest-decimal half-away rounding to six places,
including signed zero and a rounded 604800-second remainder without carry.
Python rejects integers that would silently lose precision in binary64.
The tested non-finite GPS inputs return the WGC display string `0, NaN`;
it is not a valid numeric epoch.

The reference corpus contains 1,289 WGC2 output cases, a second 22-request
replay with 1,325 rows, and independent CSPICE intermediate-bit captures.
These results cover selected inputs and a server-managed kernel set; they do
not establish exhaustive WebGeocalc, kernel or cross-platform parity. GPS
week-string input, other WGC time formats, and the corresponding JavaScript
binding remain open. See `tests/reference/wgc-gps/README.md` for hashes,
raw-response limitations and reproduction instructions.
