# stkcraft-time 0.1.8

Release date: 2026-11-11

This is a tooling release. The library API and every conversion result are
unchanged from 0.1.7.

## Mirror-friendly downloads

The offline tooling that fetches external data now accepts a user-supplied
endpoint, so a network that cannot reach the upstream host quickly can use
a mirror or a local copy:

| Script | Flag | Environment variable | Default |
|---|---|---|---|
| `tools/fetch_eop.py` | `--url` | `STKCRAFT_EOP_URL` | IERS `finals2000A.all` |
| `tools/validate_ut1.py` | `--url` | `STKCRAFT_EOP_URL` | IERS `finals2000A.all` |
| `tools/gen_dtdb_table.py` | `--url` / `--src` | `STKCRAFT_DTDB_URL` | pinned ERFA `dtdb.c` |

`--url` wins over the environment variable, and `--eop` / `--src` still
skip the download when they point at an existing file. Integrity checks
are unchanged: the ERFA source is verified against its pinned SHA-256, and
the EOP file is parsed and summarized immediately after download, so a
mirror cannot change results silently.

Example:

```sh
export STKCRAFT_EOP_URL=https://mirror.example/finals2000A.all
python tools/fetch_eop.py --out data/finals2000A.all
```

## Byte-exact downloads

The fetch scripts wrote the response through a text-mode file, which
translated line endings on Windows. The saved file therefore differed
from the upstream product even though the parsed values were the same.
Both scripts now write the response bytes verbatim.

## Compatibility

No API, kernel-format, or numerical change. Upgrade is not required for
correctness; it only affects the `tools/` scripts, which are not part of
the crate.
