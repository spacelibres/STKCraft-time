# stkcraft-time 0.1.19

Release date: 2026-11-11

This release adds a container image, which is the only artifact GitHub
Packages can host for this project.

## Why not publish the crate to GitHub Packages

GitHub Packages supports Maven, NuGet, RubyGems, npm and container
images. It has no Cargo registry, so `cargo publish` cannot target
`github.com/spacelibres/STKCraft-time/packages`. Rust consumers get the
library from crates.io; the binaries come from GitHub Releases.

A container image is supported and genuinely useful: MCP clients and CI
can run the server without installing a Rust toolchain.

## What is published

Every tag now builds and pushes `ghcr.io/spacelibres/stkcraft-time`:

| Property | Value |
|---|---|
| Tags | `0.1.19` and `latest` |
| Platforms | `linux/amd64`, `linux/arm64` |
| Contents | `stkcraft-mcp`, `sclk-check`, `ut1-check`, `tdb-compare`, `wgc-compare` |
| Default command | `stkcraft-mcp` (JSON-RPC on stdin/stdout) |
| User | `10001:10001` |
| Working directory | `/data` |
| Labels | OCI title, description, source, documentation, license, version, revision |

The runtime layer is `debian:bookworm-slim` plus the binaries; the build
stage is `rust:1-bookworm` and compiles the tagged source with
`--locked --features mcp --bins`.

Usage:

```sh
docker run --rm -i ghcr.io/spacelibres/stkcraft-time:0.1.19
docker run --rm -v "$PWD:/data:ro" ghcr.io/spacelibres/stkcraft-time:0.1.19 \
    ut1-check /data/finals2000A.all
```

## Verification

The image was built and exercised locally before release:

- `initialize` over stdin returns the tools capability and
  `serverInfo.version` matching the crate version;
- a `format_utc` call returns `2016-12-31T23:59:60.000Z` for
  `23:59:59.9999` at precision 3;
- `ut1-check /data/finals2000A.all` with a read-only mount prints
  `UT1 - UTC` for piped timestamps;
- `docker inspect` reports `User=10001:10001`, the MCP command and all
  OCI labels.

Library checks are unchanged: 108 tests by default, 120 with the `mcp`
feature, clippy with `-D warnings`, `no_std`, wasm32, thumbv7em, MSRV
1.75 and rustdoc with `-D warnings`.
