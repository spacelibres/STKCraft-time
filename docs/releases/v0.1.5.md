# stkcraft-time 0.1.5

Release date: 2026-11-10

This release turns the project into a fully published Rust crate and
GitHub release with optimized, platform-specific binaries. There are no
changes to the time-conversion algorithms.

## Highlights

- **Release-mode binaries** for Linux x86_64, macOS arm64 and Windows
  x86_64 are built with `cargo build --release --features mcp --bins`
  and attached to this release.
- **Checksums** are published as `SHA256SUMS.txt`.
- **GitHub metadata** now includes a full repository description,
  homepage, topics, release notes, community health files and citation
  metadata.
- **Package metadata** now describes the full scale set, `no_std`
  support and the MCP server, ready for crates.io and docs.rs.
- **Release profile** uses thin LTO, one codegen unit and stripped
  binaries.
- **Documentation** includes badges, installation and release sections,
  a support guide and issue/PR templates.

## Install the library

The crate is not yet on crates.io. Use the tagged repository:

```toml
[dependencies]
stkcraft-time = { git = "https://github.com/spacelibres/STKCraft-time", tag = "v0.1.5" }
```

Or:

```sh
cargo add --git https://github.com/spacelibres/STKCraft-time --tag v0.1.5 stkcraft-time
```

For `no_std` plus `alloc`:

```toml
stkcraft-time = { git = "https://github.com/spacelibres/STKCraft-time", tag = "v0.1.5", default-features = false }
```

## Prebuilt binaries

Each archive contains:

- `stkcraft-mcp` — stdio MCP server
- `sclk-check` — SCLK validation tool
- `ut1-check` — UT1/EOP validation tool
- `tdb-compare` — NAIF vs ESA TDB comparison tool
- `wgc-compare` — WebGeocalc comparison tool
- `README.md`, `LICENSE`, `CHANGELOG.md`

| Platform | Archive |
|---|---|
| Linux x86_64 | `stkcraft-time-v0.1.5-linux-x86_64.tar.gz` |
| macOS arm64 | `stkcraft-time-v0.1.5-macos-aarch64.tar.gz` |
| Windows x86_64 | `stkcraft-time-v0.1.5-windows-x86_64.zip` |

The MCP binary requires the `mcp` feature at build time, which is why
these archives are built with `--features mcp --bins`.

## MCP quick start

```sh
stkcraft-mcp
```

Example client configuration:

```json
{
  "mcpServers": {
    "stkcraft-time": {
      "command": "/absolute/path/to/stkcraft-mcp",
      "args": []
    }
  }
}
```

The server exposes `utc_to_tai`, `tai_to_utc`, `utc_to_et`, `et_to_utc`,
`tai_to_tt`, `tai_to_gps`, `gps_to_tai`, `utc_to_ut1`, `ut1_to_utc`,
`sclk_to_et`, `et_to_sclk`, `delta_at`, `lsk_info`, `format_utc` and
`etcal`.

## Verification

The release commit passes:

```text
cargo fmt --all -- --check
cargo test --all-targets
cargo test --all-targets --features mcp
cargo clippy --all-targets -- -D warnings
cargo clippy --all-targets --features mcp -- -D warnings
cargo build --no-default-features
cargo build --release --features mcp --bins
RUSTDOCFLAGS="-D warnings" cargo doc --no-deps
```

The GitHub Actions `CI` workflow runs the test, Clippy, `no_std` and MCP
jobs. The `Release` workflow runs release-mode tests on Linux, builds all
platform binaries and publishes this release.

## Compatibility

- MSRV: Rust 1.75.
- `no_std` with `alloc` is supported with `default-features = false`.
- The MCP server requires `std` and the `mcp` feature.
- No breaking API changes since 0.1.0.
