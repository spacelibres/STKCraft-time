# STKCraft-time 0.1.30

Adds an explicit N0067 ET-to-JDUTC path for native consumers such as
historical SPK type-10 initialization. `TimeContext::et_to_spice_julian_utc`
returns `NaifJulianUtc` without an integer Epoch or civil-calendar round trip.
Existing strict civil/scientific APIs keep their model and coverage choices.

Independent C captures precede implementation. All 13 original historical
integration inputs match; the expanded matrix checks 18,493 unrounded native
values and 185 exact native error symbols. Another 185 malformed-table
records are retained as earlier typed-constructor rejections, without
claiming native symbol equivalence. See
[the exact scope](../reference/NATIVE_JDUTC.md).

The new method preserves native pre-first-entry extrapolation, leap-second
formal-date behavior, operation order and 140-entry selection. It rejects
SOFA/frozen models rather than silently changing conventions. Production
remains pure Rust with no CSPICE dependency. Complete TTRANS/WebGeocalc
conformance and end-to-end historical SPK10 geometry are not claimed.
