# stkcraft-time 0.2.1

This documentation maintenance release corrects the Python and JavaScript
support matrix for native partition-aware SCLK and WebGeocalc GPS week/TOW
methods. It also distinguishes WGC MCP tools that accept an LSK from legacy
GPS tools that do not. The calculation code and its numerical contracts are
unchanged. A regression check detects the two previously misleading claims.

The Rust crate and language adapter release metadata are synchronized to
0.2.1. See [the support matrix](../BINDINGS.md) for artifact and publication
status and the [API guide](../API.md) for the exercised numerical scope.
