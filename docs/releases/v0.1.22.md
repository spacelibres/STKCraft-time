# stkcraft-time 0.1.22

Release date: 2026-11-12

Documentation audit release. There is no library, kernel-format or numerical
change from 0.1.21.

## What the audit found

The repository grew through 0.1.16-0.1.18 and added the `contract` module,
the N0067-compatible decimal parser, partition-domain SCLK validation and a
10 871-case CSPICE fixture. Several documents still described the previous
behaviour.

### Corrected statements

| Document | Was | Now |
|---|---|---|
| `docs/API.md` scope | "does not bundle mission data … caller supplies leap seconds" | the `naif0012.tls` snapshot is compiled in; mission SCLK and EOP are not |
| `README.md` `no_std` | `libm` supplies `sin`, `floor`, `round` and `fmod` | `sin`, `cos`, `floor`, `round` |
| `docs/MCP.md`, MCP skill | every tool accepts `lsk_path` | only the tools whose schema has it; GPS tools and `etcal` take no kernel |
| `docs/MCP.md`, MCP skill | partitions parsed, ticks always available | encoded ticks are bounded by the cumulative partition duration |

### Completed API index

`docs/API.md` did not index everything that is public. Added:

- the whole `contract` module: `TimeContext`, `ScientificContext`,
  `NaifEt`, `IauTdb`, `NaifMetadata`, `ScientificModel`,
  `CalculationProfile`, `ContractError`;
- `error` (`TimeError` variants) and `mcp` (`run_stdio`, `handle_message`);
- `lsk::parse_lsk`;
- `SclkClock` / `SclkMap`;
- `DtdbError`, `dtdb_minus_tt_split`, `dtdb_minus_tt_at_observer`;
- `Formatter::with_options`.

## Documentation ownership

`docs/API.md` now states the three sources and their roles:

| Source | Role |
|---|---|
| `docs/API.md` | authoritative in-repository API contract and call patterns |
| `docs/TIME_CONTRACT.md` | model contracts: units, origins, bounds, reproducibility |
| Project wiki | narrative explanations and the verification record |

If they disagree, the API guide and the source win; the wiki is updated from
the same facts.

## Wiki corrections

The wiki was aligned with the committed fixtures:

- SCLK validation is 10 871 bit-exact CSPICE cases (2 719 forward, 8 152
  inverse) across the `MRO_SCLKSCET` and JUICE kernels, replacing an earlier
  64-sample tolerance statement.
- The cumulative partition domain, the `SclkClock`/`SclkMap` helper, the
  `contract` types, and the committed fixture table
  (`contract_utc` 910, `naif_numbers` 800, `dtdb_observer` 724,
  `pre_1972` 93) are now documented.
